# LogServer - Высоконагруженный асинхронный TCP-сервер логирования

## Описание

TCP-сервер для централизованного сбора логов с множества клиентов (IoT, микросервисы). 
Асинхронная обработка, потокобезопасная очередь, запись в единый файл.

Логи записываются в services/logs/logs.txt

## Технологии

- .NET 9

## Быстрый старт

### Docker
# Из корня проекта

# Собрать образ
docker-compose build

# Запустить в фоне
docker-compose up -d

# Остановить если нужно
docker-compose down
